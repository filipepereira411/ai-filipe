# AI Filipe

Simulação "AI Sponge" adaptada para "AI Filipe" — aplicação web estática educativa e divertida.

Funcionalidades:
- Chatbot local (respostas pré-definidas e brincadeiras com "pepinos"/Bubble Bass)
- Botões rápidos para temas (Pepino, Bubble Bass, Origem)
- Captura de mensagens e respostas no browser (sem backend)

Como usar:
1. Clone o repositório
2. Sirva com um servidor estático, por exemplo:

```bash
python3 -m http.server 8000
# depois abrir no browser:
http://localhost:8000/
```

Créditos: inspirado no meme "Bubble Bass" e na ideia do "AI Sponge".
