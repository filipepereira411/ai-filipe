# AI Filipe — Versão Final

Esta é a versão final do "AI Filipe": uma simulação local inspirada no conceito "AI Sponge" e nas criações de fandom (AI Generated Sponge). O site é estático (HTML/CSS/JS) e funciona totalmente no browser.

O que fiz:
- chat local com respostas divertidas e rápidas
- secção "Origem" com referência à wiki de fandom
- página de personagens (lista a partir de data/characters.json)
- animação de bolhas para estética underwater
- navegação simples entre chat e personagens

Como correr localmente:

```bash
python3 -m http.server 8000
# abrir no browser
http://localhost:8000/
```
